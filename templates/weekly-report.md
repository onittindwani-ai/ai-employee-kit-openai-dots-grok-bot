# Weekly report template

Used by: [Weekly Client Report Builder](../employees/operations/02-weekly-client-report-builder.md), [Daily Founder Brief](../employees/operations/08-daily-founder-brief.md) (for its Friday wrap up).

A client report that is the same shape every week is faster to read and easier to trust. Copy the block below into your document tool once per client, fill the setup table, and give the link to your AI employee.

## Setup (once per client)

| Field | Your answer |
| --- | --- |
| Client | |
| Their main goal this quarter | |
| The 3 to 5 numbers they care about | |
| Where each number lives (tool and report name) | |
| Who reads the report | |
| Day and time it is due | |

## The report (copy from here)

```text
WEEKLY REPORT: <Client>, week of <date>
Prepared by: <your company> (draft, reviewed by <your name> before sending)

1. THE WEEK IN ONE LINE
<one sentence on what changed and why it matters to their goal>

2. KEY NUMBERS
| Number | This week | Last week | Change | Source |
| <number 1> | | | | |
| <number 2> | | | | |
| <number 3> | | | | |

3. WHAT WENT WELL
- <fact, with the number behind it>

4. WHAT DID NOT GO WELL, AND WHAT WE ARE DOING ABOUT IT
- <fact> : <our next action>

5. DONE THIS WEEK
- <task>

6. NEXT WEEK'S PLAN
- <task, owner, day>

7. WHAT WE NEED FROM YOU
- <item, by when>

CHECK FLAGS (internal, delete before sending)
- <any number that looks wrong or could not be loaded>
```

## Rules for whoever fills it in

- Every number has a source. No source, no number.
- Report a bad week as clearly as a good one.
- If a reason for a change is not known, say "reason not known yet" instead of guessing.
- Delete the CHECK FLAGS section only after you have checked each flag.

## Filled example (synthetic)

```text
WEEKLY REPORT: Example Logistics Co, week of Monday (example)

1. THE WEEK IN ONE LINE
More quote requests were answered within 10 minutes, and meetings held steady.

2. KEY NUMBERS
| Number | This week | Last week | Change | Source |
| Quotes answered within 10 min | 182 | 140 | +42 | Help desk report |
| Meetings booked | 6 | 6 | 0 | CRM |
| Website visits | 9,800 | 980 | CHECK | Analytics |

3. WHAT WENT WELL
- 182 quotes answered within 10 minutes, the best week so far.

4. WHAT DID NOT GO WELL, AND WHAT WE ARE DOING ABOUT IT
- Meetings did not grow with quotes : testing a shorter booking link next week.

7. WHAT WE NEED FROM YOU
- Access to the ad account, by Wednesday.

CHECK FLAGS
- Website visits jumped 10 times. Possible tracking change. Not used in the summary.
```
