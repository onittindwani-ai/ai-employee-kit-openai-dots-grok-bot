## How teams work in each tool

- **Grok Bot:** each employee is its own bot. xAI says bots work in parallel, message each other, share context in threads, and can coordinate in a group chat. Each recipe gives you the group chat message to paste.
- **OpenAI Dots:** today you have one personal dot. Each employee becomes a project for that dot, and OpenAI says a dot can run a project while working on several others. Each recipe gives you the message that links the projects. OpenAI says teams of dots are planned for the future.

## Start small

Set up the employees one at a time, run each on a small batch, and check the work for a few days. Then join them into a team.
