# Changelog

## v1.0.0 (2026-11-06)

First release.

- 25 AI employees: 9 sales, 8 hiring, 8 operations. Each has a full setup prompt for OpenAI Dots and for Grok Bot, rules and permission points, a report format, a synthetic sample and a 2 minute check.
- 8 team recipes with hand off tables, including a chief of staff bot that runs specialists.
- CHOOSER.md: which tool to use for each of the 25 jobs, and when a custom build in Claude Code is the better choice.
- SAFETY-AND-PERMISSIONS.md: the rules every employee follows and how to set each tool's own controls.
- 4 templates: candidate scorecard, ideal customer profile, CRM field map, weekly report.
- SOURCES.md: every product fact, checked against official pages on 2026-11-06.
- tests/check_kit.py and a GitHub Actions workflow that runs it on every push.
